# Hindi InScript Keybr

A production-oriented Devanagari InScript typing trainer.

## Features

- Hindi/Devanagari typing with Unicode-aware comparison
- BIS/Windows-style InScript keyboard model with finger assignments
- Progressive lessons from home row to sentences
- WPM, accuracy, error count, and key difficulty statistics
- Responsive interactive keyboard preview
- Vitest regression tests and GitHub Actions CI

## Development

```bash
npm install
npm run dev
```

Run tests with:

```bash
npm test
```

Build for production with:

```bash
npm run build
```
